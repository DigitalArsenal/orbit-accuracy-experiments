# Native operator-state and covariance normalization

This amendment converts the actual epochs selected from every downloaded
operator OEM or full-state I11 product. It preserves the old native inventory,
full Starlink fidelity run and historical model comparisons. It does not
reclassify forecasts as independent truth.

For I11, expand the native compact OEM's declared start/step/endpoint exactly.
Those states were generated by the native IESS-412 formulation; they are
operator-model samples, not independently measured Cartesian states. Record
this distinction in every result. Keep position-only products and the separate
SP3 physical run in the full resource accounting without using placeholder
velocity slots.

For each product, set the diagnostic fitting endpoint 24 hours after its first
state. Select nearest actual epochs on the registered 10-minute fitting grid
and 30-minute scoring grids at 1, 3 and 7 days. Keep the 45-second epoch
tolerance, unique actual states, 90% coverage and original time labels. This
single-product selection measures forecast/model closure only; its diagnostic
endpoint is not an asserted observation or publication epoch. Later scoring
retains the source creation time and observation-time comments.

Use native foundation/frames for full-state EME2000 or Earth-fixed conversion
to GCRF, and native gp-error-model source_covariance for each supplied full
6x6 covariance at the exact selected epoch. No host rotation, invented sigma,
covariance substitution or propagated zero velocity. Source-local identity
remains intact; a provisional or zero catalog ID is never promoted to a
verified global identity. A missing covariance stays unavailable; a covariance
conversion failure remains explicit even when state conversion succeeds.

Pin every module and adapter, the inventory, corrected Starlink outcomes and
IERS EOP stream before conversion. Require bracketing EOP for Earth-fixed
states and retain predicted/observed labels. Unsupported frames, absent
velocities, malformed times and coverage gaps remain per-product outcomes.
Preflight uses the first product per source/format class only to verify
execution; the full normalization has no spacecraft cap.

Admission requires finite ordered states, exact source/index/epoch linkage,
native GCRF/UTC outputs and covariance method/status provenance. The existing
SOFA/Vallado frame criteria and covariance-transform E2E remain unchanged.
No propagator accuracy, empirical covariance calibration or collision-risk
success is claimed by this normalization stage.
