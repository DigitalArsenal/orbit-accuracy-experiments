# Direct public-feed acquisition

Registered 2026-10-26, before fetching source bodies for this extension.
The owner clarified that the SDN nodes are intentionally stopped during the
rewrite and authorized direct feeds. Local node availability is not an upstream
availability test. This acquisition extends the parent census; it does not
change the inputs or numerical rules of the running `catalog-epochs` benchmark.

Use the pinned ephemeris-source portable WASM module to plan and discover every
anonymous source in its 17-source registry. Fetch complete resources directly
over HTTP. Never use a spacecraft sample, first-N resource limit or byte-range
prefix. Retry transient failures twice; retain every terminal failure. Four
HTTP workers limit load, not population. Per-response limits refuse oversized
responses explicitly; they never silently truncate or mark partial data complete.
Use HTTPS for ESA's HTTP registry URLs, recording both URLs. Credentials and
restricted adapters are outside this anonymous acquisition; previously acquired
archives remain available and those four registry entries remain in accounting.

Extend metadata discovery where the module's live-feed selection omits public
ephemerides: every Planet hardware ID in the public TLE identity crosswalk gets
its complete OEM; all Intelsat ECF/weekly/extended/maneuver option values are
retained; every linked SP3 product in the planned GNSS week directories and
every Swarm spacecraft's newest linked SP3 are retained. These are record and
URL operations, not orbital calculations. Native discovery failures remain
visible even if a listing independently yields supplementary resources.
The scope is all spacecraft advertised by the current feeds and their planned
listing windows, plus existing archives, not every historical file on the web.

Freeze listings and the complete discovered queue before bulk retrieval. Store
exact decoded HTTP entity bytes losslessly compressed by SHA-256 under the
ignored run directory; retain retrieval time, original/final URL, selected HTTP
metadata, attempts, length and original/compressed hashes. Resuming a run never
refreshes listings or replaces successful bytes. No raw states, TLEs, HTML
listings or per-object tables are published. No fake IPFS identifiers are used.

The portable module validates raw containers and extracts declared coverage
where supported. Missing identity coverage or raw validation is explicit;
successful downloading is not successful orbital decoding. The next numerical
run must independently freeze normalization, frame/time, fit and reference
eligibility. Operator forecasts are not independent truth; GP-only feeds are
catalog membership, not high-accuracy reference. No collision probability or
accuracy conclusion follows merely from this acquisition.

Acceptance: all 17 sources accounted for, every discovered resource terminal,
all successful artifacts rehashed from lossless storage, exact queue/result
agreement, native listing replay, and native validation replay on each acquired
format. The E2E uses actual public feeds and the actual retained archive. Report
source/discovery/download/validation gaps separately and fail full-coverage
claims if any remain. An interrupted job remains resumable and incomplete.
