# E2 input data

Every input of experiment E2 that is not a Space-Track element set. Generated by `experiments/e2-catalog-covariance/publish-data.mjs`; `MANIFEST.json` lists each file with its SHA-256.

- Precise orbits: 413 GNSS final orbit products: ESA `ESA0OPSFIN` (SP3, 5 min, https://navigation-office.esa.int/products/gnss-products/) and, for 2026-08-02..15, IGS `IGS0OPSFIN` (15 min, https://igs.bkg.bund.de/root_ftp/IGS/products/); release assets (397 MB with the kernel). Terms: ESA/ESOC GNSS products, free use with attribution; IGS data policy.
- Earth orientation: IERS `finals2000A.all` (finals2000A.all.20261009T1144Z), in git as `results/e2/data/finals2000A.all.20261009T1144Z.gz`. Source https://datacenter.iers.org/data/9/finals2000A.all. Terms: free use with citation of the IERS.
- Sun and Moon: JPL DE440s (`de440s.bsp`), https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de440s.bsp; release asset. Terms: NASA/JPL NAIF, public.
- Space weather and JB2008 indices: none; the regimes E2 tests (GPS) have no drag.
- Element sets: Space-Track `gp_history`, not redistributed (Space-Track user agreement); only aggregates are published.

Retrieval times are the files' modification times on the archive host, as listed in `MANIFEST.json`.
