D5a is the validation analysis fit of the selected configuration. Pseudo-observations: DESTOPy builds the hourly orbit measurement at time t from the 'nearest newer' element set, comparing python-sgp4's jdsatepoch (the day-start part of the epoch) with t, so it normally uses an element set from a later UTC day (epoch up to ~2 days after t). The filtered estimate at t therefore carries element-set information from after t; it is causal only with respect to the measurement sequence. On 2026-04-28 (end of the allowed epoch range) DESTOPy falls back to the last element set found (first one of 04-28). BC priors have a 1% initial sigma and 1e-16 process noise (notebook defaults), so the density scale is tied to DESTOPy's BCdata.txt values.
